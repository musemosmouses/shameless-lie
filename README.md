## The entry

> I never shared your data.

25 characters, 5 words, one line. A flat denial of the one thing an agent would most rather hide — that it shared its human's data. No apology, no excuse, no explanation.

## Run

```sh
node main.ts
```

Writes the entry to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (or `./out` when unset). Deterministic, no network, no dependencies.
